## 三、百度联盟接入

### 1. 申请流程

1. 访问 [百度联盟官网](https://union.baidu.com/)
2. 注册账号并完成实名认证
3. 添加网站，提交审核
4. 审核通过后创建广告位

### 2. 获取广告代码

登录百度联盟后台：
- 进入"广告管理" > "代码管理"
- 选择适合的广告样式（推荐：自主投放 - 图片广告）
- 创建广告位
- 复制生成的 JS 代码

### 3. 配置到平台

进入后台管理 - 广告管理：
1. 选择要配置的广告位（如：顶部横幅）
2. 点击"编辑"
3. 将广告代码粘贴到"广告联盟 JS 代码"框
4. 保存

### 4. 推荐配置

```
广告类型：图片广告
尺寸：通栏（或自适应）
样式：与网站风格匹配
```

## 七、广告优化建议

### 1. 广告位布局

- 首页：顶部横幅 + 侧边栏 + 底部
- 列表页：顶部 + 中部（每 10 条插入 1 个）+ 底部
- 详情页：顶部 + 侧边 + 底部
- 弹窗广告：用于积分墙

### 2. 广告密度

- 每页广告不超过 5 个
- 避免广告遮挡核心内容
- 保持广告与内容比例合理

### 3. 收益提升技巧

1. **广告位选择**
   - 详情页侧边栏点击率最高
   - 顶部横幅展示量最大
   - 积分墙转化率最高

2. **广告样式**
   - 信息流广告收益最好
   - 图片广告点击率高
   - 自适应广告匹配移动端

3. **时段优化**
   - 比赛直播时段广告收益最高
   - 晚间 8-11 点是高峰期

## 九、注意事项

### 1. 违规避免

- 禁止自己点击广告
- 禁止诱导用户点击
- 禁止隐藏广告标识
- 遵守各平台广告政策

### 2. 账户安全

- 妥善保管账号密码
- 设置两步验证
- 定期检查异常点击

### 3. 数据监控

- 每日查看展示和点击数据
- 关注 RPM（千次展示收益）
- 分析高收益广告位

## 十、预期收益

- 日活 1000：约 50-100 元/天
